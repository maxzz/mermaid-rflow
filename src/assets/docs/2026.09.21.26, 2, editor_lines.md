# Editor line properties popover
_Exported on 9/21/2026 at 15:28:15 PDT from Cursor (3.21.16)_

---

**User**

It is necessary to add a popover in the editor panel toolbar that displays the properties of a selected line—specifically if that line represents a `style` or a `linkStyle`. 
This popover should show the name of the node for which these properties are defined, as well as attributes such as `fill`, `stroke`, `stroke-dasharray`, and the rest of available  settings applicable to these lines.

The popover shows node `D · Debug` with fill, stroke, and dash. I’ll change a value next to confirm it writes back, then check a `linkStyle` line.

Edits write back correctly, but the popover loses the line after the first patch. I’ll lock the inspected line while it stays open.

The editor toolbar now has a **line properties** popover (the table-properties icon, left of the layout-engine control).

Put the caret on a `style` or `linkStyle` line and open it. It shows:

- **What the line is** — `style` or `linkStyle`
- **Who it applies to** — node id and label (`D · Debug`) or the resolved edge (`Start → Debug`)
- **Declared attributes** — `fill`, `stroke`, `stroke-dasharray`, `stroke-width`, text/label color, opacity, fonts, corner radii, and `interpolate` on links
- **Empty applicable fields** so you can set the rest of the usual Mermaid CSS for that kind of line

Changing a control rewrites that source line. If the caret is not on a `style` / `linkStyle` statement, the popover explains that instead of showing properties.
