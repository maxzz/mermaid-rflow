**What you'll see:**
- **Timing:** every 1.2 to 4.5 seconds, whatever the octopus is doing, a small splash lands somewhere on the swamp.
- **Placement:** the spot is picked inside an ellipse that fits the puddle, using only the inner 70% of it so splashes stay away from the edge.
- **Size:** each splash is about 20–32% the size of the octopus splash. It has 4–6 drops and a small spout, and the drops fall faster because they don't fly as high. Splashes nearer the viewer come out slightly larger.
- **Rings:** each splash sends out 2 or 3 staggered rings, sized to the splash, which fade as they spread. They're clipped to the puddle outline so they never cross onto the asphalt. Overlapping splashes are fine, and each one removes itself when finished.
- **Reduced motion:** if the user has reduced motion turned on, these splashes are switched off, the same as the bubbles.

**How the rings match the sign's perspective:** the "Enter Labs" label is tilted back 62° with a 120px perspective, both centred at (220, 258). The new file `b-swamp-surface.ts` does the same projection in JavaScript. Each ring is a real circle on the water plane, turned into points on screen, so it comes out as a slightly egg-shaped ellipse with the far side smaller. The sign in `4-swamp-enter-button.tsx` now takes its tilt and perspective from the same `SWAMP_SURFACE` constants, so if you change the sign's angle the rings follow.

**One visual caveat:** the sign's 62° tilt makes the rings about 0.47 as tall as they are wide. The puddle outline and the octopus ripples are much flatter, at about 0.11. That's what you asked for, but the rings may look rounder than the puddle. If so, raise `tiltDeg` or `perspective` in `SWAMP_SURFACE`; this also changes the sign.

**Other changes:**
- In `a-swamp-atoms.ts`, `createSplashDrops` now accepts a scale and a drop count, and there are new atoms for the small splashes. `resetSwampAtom` clears them too.
- In `5-swamp-splash.tsx`, `Spout` and `SplashDrop` now take an impact point and a scale. The octopus splash still uses the same values, so it looks unchanged.
