# Flow node zoom option
_Exported on 9/28/2026 at 20:19:31 PDT from Cursor (3.22.12)_

---

**User**

In the "Flow" tab, when a node (i.e., a line of text editor) is selected in the left-hand section of the editor, the corresponding node is selected in the right-hand section; however, after the node is selected, the entire view focuses on that node and zooms in.	

We need to add an options popover—similar to the one in the SVG tab—containing a setting to disable zooming and focusing the view on the selected element (so far just this one but latter there will be more options); this would ensure the entire graph on the right remains at its current scale and position, rather than following the default behavior of scrolling to and zooming in on the selected node.

---

**Cursor**

I'll look at how the SVG tab's options popover works and how Flow currently zooms to a selected node, so the new setting can keep the graph at its current scale and position.

The Flow tab zooms with `fitView` when an editor line is selected. I’ll add a settings popover next to the menu, with a switch that leaves the canvas scale and position alone.

The Flow tab now has a settings popover beside the menu, with a **Focus selection** switch.

With the switch on, clicking a line in the editor still selects the matching node or edge and zooms the canvas to it. Turn it off and the canvas stays at its current scale and position while the selection still updates. The choice is saved with the other Flow canvas settings, and it starts on so the previous behavior remains until you change it.
