**User**

On the "Flow" tab (as shown in the screenshot): when a user selects a line in the diagram source code editor (on the left), the corresponding block on the right should not appear as selected with a rectangle with a dark blue border.

If the block's content consists of a single letter, it should appear as a circle; otherwise, it should appear as a rectangle with fully rounded corners.
The node name (not its label) should be displayed inside this circle.

Additionally, when this new marker appears, a quick animation should play, moving from the center of the block to its top-left corner.
The Motion library should be used to implement this animation.

Also, when a connection line between blocks is selected in the code editor, a label (e.g., "A --> B", indicating the connection) should be displayed on the graph at the start of that line.

For state management, the React components should use either Jotai or Valtio—
whichever is more appropriate—instead of standard state management provided by React.
This simplifies component reuse throughout the application.
Implement the new functionality in separate files/folders so that it does not mix with the rest of the code.

Minimize the use of `useCallback` and `useEffect` in React components in favor of Jotai’s `set` atoms and derived atoms (where necessary), or use Valtio’s reactivity where appropriate. 

A similar block selection mechanism will be implemented for other tabs as well. Since this functionality should be reused wherever possible, it needs to be implemented in a separate folder.

**Cursor**

The Flow tab currently outlines the matching node with a dark blue rectangle. I’ll look through how source selection maps onto the canvas so the marker can become a named circle or pill that animizes into the node’s top-left corner, and so edge selections get a connection label.

The blue outline comes from the editor-to-canvas link. I’ll replace it with a reusable marker: a named circle or pill that travels to the node’s top-left, and a connection caption at the start of a selected edge.

Selecting a line in the editor on the Flow tab no longer draws a dark blue rectangle around the matching block. A badge with the node id appears instead, and a selected connection shows its source text at the start of the line.

- A one-letter id, such as `C`, is a circle. A longer id, such as `n1`, is a pill with fully rounded corners. The text is the node id, not the label (`C`, not `Ship it`).
- When the badge appears, Motion moves it from the center of the block to the top-left corner. After that, panning and zooming keep it on the corner without replaying the flight.
- A connection line shows a caption such as `A --> B` or `B -->|Yes| C` beside the start of that line. Mentions of the endpoints on that line do not also badge those blocks. A line that both declares a node and draws an edge shows both.

The shared pieces live in `src/components/2-main/2-editor-page/2-panel-diagrams/4-source-pick`. Other tabs can reuse `SourcePickLayer`, `placeNodeMarker`, and `markerShape`. The Flow adapter is in the `rflow` folder inside that directory, and the canvas only mounts `RflowSourcePick`.

Which line is selected still comes from the existing Valtio `sourceLink` store. Whether the entrance animation has finished is a Jotai atom, set when the Motion animation completes, so later viewport moves do not replay it. The new components do not use `useState`, `useEffect`, or `useCallback`.
